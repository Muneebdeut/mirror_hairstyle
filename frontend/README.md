# AI Hairstyle Advisor - Frontend

Next.js 14 App Router single-page web application featuring responsive luxury styling, drag-and-drop photo uploader, facial shape breakdown, preference filtering, top recommendation cards, and interactive before/after virtual try-on slider.

## Features

- **Next.js 14 App Router & TypeScript**: Clean, modular component architecture.
- **Tailwind CSS & Glassmorphism Design**: Premium dark-mode UI aesthetics.
- **Interactive Before/After Slider**: Real-time side-by-side comparative slider comparing user photo against AI try-on result.
- **Non-Gender Preference Selector**: Filter recommendations via `Masculine`, `Feminine`, `Unisex`, or `No Preference` without gender classification.
- **Hair Profile Editor**: Allows users to manually refine hair length, texture, and density.

## Running Locally

```bash
cd frontend
npm install
npm run dev
```

App will run at: `http://localhost:3000`
